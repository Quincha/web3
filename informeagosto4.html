2. Desglose de Módulos Recientes & Features Desplegado

🎨 Módulo Diseños / Bordados (Wilcom TrueView) Completo

Catálogo fotorrealista de bordados con soporte multinativo para archivos de máquinas industriales y domésticas:

  • Parser Multi-formato Nulo Dependencias: Parsea binary .JEF, .DST y .PES respetando códigos de salto, corte de hilo y paletas de color con precisión pyembroidery.
  • Renderizado TrueView en 1 Pasada: Simulación fotorrealista de hilo con iluminación difusa y antialiasing analítico por capsula. Se eliminó el supersampling 2× eliminando los Error 524 de Cloudflare.
  • Persistencia & API REST: Endpoints integrados en Express con persistencia en DATA_DIR/designs/ y metadatos relacionales en la base SQLite del servidor.

💳 Módulo Finanzas & Deudas (Caso Covili & Abonos) Producción

Gestión completa de saldos, cuentas por cobrar/pagar y registros contables:

  • Sincronización Directa BD Producción: Deuda cargada por $1.300.000 (abonado $107.000, saldo $1.193.000). Preservadas deudas previas.
  • Historial de Abonos Granular: Modelo ampliado con payments?: Abono[], helper addPago() en FinanceContext y modal UI dedicado en DebtsBalanceView.tsx (eliminando la ventana modal de navegador prompt).

3. Arquitectura del Sistema Infraestructura

💻 Frontend Application

React 19 + TypeScript. Modulares React Contexts para salud, hábitos, finanzas, tareas y smartband. Diseño UI ultra-oscuro con estética futurista.

⚙️ Express Backend Server

Node.js v24 con SQLite nativo. Sin bibliotecas C++ nativas externas como sqlite3 o better-sqlite3, garantizando cero fallos de binarios en ARM/Raspberry Pi.

🌐 Despliegue & SSH Proxy

Pipeline directo vía PowerShell (quincha-connect.ps1) sobre SSH/PSCP y túnel seguro Cloudflare. Reinicio transparente del servicio systemd quincha-systems.
