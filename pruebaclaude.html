Arquitectura de capas

4 capas claramente separadas: presentación (componentes), estado (contextos), servicios (permisos, sync) y persistencia (localStorage).

🖥️

main.tsx

Entry point React 19 · Tema + 12 providers anidados

⚛️

App.tsx

Router interno · Detecta ?mode=client para portal

🌀

TransitionManager

FSM de vistas: landing → transition → dashboard

↓
🧩

components/

UI primitivos (Card, Button, Badge, Avatar) · Layout (Sidebar, CommandPalette) · módulos por dominio

📦

context/ · 12 providers

Theme · User · Transition · Tasks · Habits · Pomodoro · Bujo · Health · Finance · Clients · Shopping · Insights

🎨

widgets/

Tarjetas reusables: Stats, Tasks, Bujo, Health, Habits, Calendar, Pomodoro, Productivity, Projects, ProactiveInsights

↓
🛡️

services/

PermissionService: matriz role × module × action
SyncQueueService: cola offline

💾

localStorage

Persistencia con prefijo quincha_* · Cache modules · Estados de ánimo · Productos · Config usuario

🎭

theme/

Design tokens (colores, espacios, radios, sombras) · Modo oscuro primario con acentos

🧠 Sistema de permisos

PermissionService implementa una matriz declarativa role × module × action con 5 roles y 7 acciones sobre 15 módulos.

super-admin: todo, incluido admin
admin: gestión completa
supervisor: ver + crear + editar
user: uso personal
guest: solo lectura

🎬 Pipeline de animaciones

GSAP orquestado en cada cambio de vista con back.out(1.2) y stagger de 80ms.

gsap.fromTo('.gsap-stagger-item',
  { opacity: 0, y: 30, scale: 0.98 },
  { opacity: 1, y: 0, scale: 1,
    duration: 0.6,
    stagger: 0.08,
    ease: 'back.out(1.2)' }
)

Lo que hace especial a Quincha

🎯

Bullet Journal de verdad

Implementa los símbolos estrictos del método original: distinción visual entre ● tarea y ○ evento, migración →, reagendado ←.

🧠

Auto-detección de tienda

Pegar una URL en Compras detecta automáticamente Amazon, MercadoLibre o AliExpress según el hostname.

💊

Salud con perfiles

Un módulo para toda la familia. Perfil principal + perfiles familiares, medicación con stock y contactos de emergencia.

🔍

Búsqueda full-text

Búsqueda en Bullet Journal combinable con filtros rápidos (hoy, semana, pendientes) y tags personalizados.

⌘

Command Palette

Apertura con Cmd+K sobre todo el dashboard para navegar rápidamente entre módulos sin tocar el sidebar.

🚪

Portal cliente aislado

Acceso vía ?mode=client que monta un árbol de providers reducido, ideal para entregar a clientes.

🏷️

Tags personalizables

Por defecto: Trabajo, Clientes, Personal, Sistema, Estudio. Los usuarios pueden agregar tags custom al vuelo.

🎨

Logo animado SVG

El logo oficial se anima con GSAP en el login. Grid de fondo con máscara radial crea atmósfera sin distraer.

📊

Insights automáticos

El módulo Finance genera insights contextuales: deudas vencidas, presupuesto al 90%, fechas críticas.
